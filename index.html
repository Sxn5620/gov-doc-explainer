Quick Start Guide

Step 1: Clone the Repository

Get the code on your machine:

git clone https://github.com/Sxn5620/gov-doc-explainer.git cd gov-doc-explainer

Step 2: Start a Local Server

Choose one method:

Using Python 3:

python -m http.server 8000

Or using Node/npm:

npx http-server

Or using VS Code:

Install Live Server extension, then right-click index.html → "Open with Live Server"

Step 3: Open in Browser

Visit: http://localhost:8000

Step 4 (Optional): Install Ollama for Better Performance

For offline, faster AI processing:

1. Download from ollama.ai

2. Pull a free model:

ollama pull mistral

3. Ollama will run at http://localhost:11434

The tool will automatically detect and use it!

Step 5: Use the Tool

1. Click the "🔍 Start Analyzing" button below

2. Select which screen/window to capture

3. Navigate to a government document (e.g., Texas Statutes)

4. Scroll through the document - explanations appear automatically!

Troubleshooting

Nothing happens when I click "Start"

• Open browser console (Press F12) and look for errors

• Make sure you grant permission to capture screen

• Check that your browser supports Screen Capture API (Chrome, Edge, Firefox)

Explanations are slow

• Install Ollama for much faster processing

• The free HuggingFace API may be rate-limited

"Cannot connect to localhost:11434"

• Ollama is optional - the tool works without it

• If you want to use Ollama: install from ollama.ai

• Run ollama pull mistral before starting
